# Myjobpage — 인증 프로젝트 현황 대시보드

교육용 가상 데이터로 만든 Streamlit 대시보드입니다. 실제 고객·시험 정보가 아닙니다.

## 기능

- 사이드바 다중 선택 필터(시험분야 / 적용규격 / 담당엔지니어 / 진행상태 / 시료상태)와 기준일
- 요약 카드, 시험분야별 막대그래프, 진행상태 도넛 차트, 프로젝트 목록(필터 결과 기준)
- 잔여일수와 일정 상태(완료 / 지연 후보 / 오늘 마감 / 진행 예정 / 일정 확인 필요), 지연 후보 행 강조
- 시험분야 카테고리 관리(등록 / 이름 변경 / 삭제, 사용 중이면 재분류 후 삭제)
- Excel 다운로드(전체 / 필터 결과): 프로젝트목록, 상태별집계, 담당자별집계, 분석조건 시트
- 시험 자원 상태 카드(조회 전용), 의뢰 상세 조회와 메모 수정

변경한 카테고리와 메모는 브라우저 세션(session_state)에만 보관되며 세션이 끝나면 사라질 수 있습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run cert_dashboard.py
```

## 파일

- `cert_dashboard.py` — 대시보드 앱
- `data/SB_project_demo.csv` — 인증 의뢰 가상 데이터
- `data/SB_resource_demo.csv` — 시험 자원 가상 데이터
